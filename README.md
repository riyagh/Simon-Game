# Simon Game

This is a simple implementation of the **Simon Game** using **HTML, CSS, and JavaScript** with **jQuery**.

# How to Play
1. Press any key to start the game.
2. The game will show a colored button sequence. Memorize it.
3. Click the buttons in the same order as shown.
4. If you repeat the pattern correctly, the next sequence will be longer.
5. If you make a mistake, the game will restart.

# Features
- Randomly generated color sequences.
- User input validation.
- Audio feedback for correct and incorrect clicks.
- Level progression.
- Game over screen with restart functionality.

# Technologies Used
- HTML
- CSS
- JavaScript
- jQuery

# Setup Instructions
1. Download or clone this repository:
   ```sh

   ```
